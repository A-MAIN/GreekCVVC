# GreekCVVC
an Extended reclist for the Greek Language for use in UTAU & OpenUtau.

for the time being both the Base Oto Ini file, and Presamp ini file for use with the plugin in vanilla UTAU, are still **wip**.

Structure
---
the Base Oto follows Gyroflex's French & Makku's Italian in structure and ARPASing English for entry phoneme placement. Since it follows a connecting speech phenomena it doesn't need to be structured like any VCCV reclist as it already sounds natural as-is with practice.

it has lists in the following order: 
CV-VC, CCV-VCC, C-C, V-V, V-R / C-R, and the Optional Glottal Stop Vs, & Breaths.

and they are formatted like this in the OTO file: 
`- v`, `-cv`, `-ccv`, `cv`, `ccv`, `v c`, `v cc`, `c c`, `c cc`, `v R` / `v -`, `c R` / `c -`, `vc R` / `vc -`, `v` / `c` / `cc` (longated)

this Reclist follows the OGSD Annotation (and Greeklish by extension), please follow the [Phoneme Guide](https://github.com/A-MAIN/Open-Greek-SinginDataset/blob/main/PHONEMEGUIDE.md) for any pronounciation examples.

the suggested recorded tempo is 120 BPM by default, however you can also go as low as 95.
