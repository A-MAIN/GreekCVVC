# GreekCVVC
an Extended reclist for the Greek Language for use in UTAU & OpenUtau.

for the time being both the Base Oto Ini file, and Presamp ini file for use with the plugin in regular UTAU, are still **wip**.

Structure
---
the Base Oto follows Gyroflex's French & Makku's Italian in structure, and has lists in the following order: 

CV-VC, CCV-VCC, C-C, V-V, V-R / C-R, Glottal Stop Vs, & Breaths.

this Reclist follows the OGSD Annotation (and Greeklish by extension), please follow the [Phoneme Guide](https://github.com/A-MAIN/Open-Greek-SinginDataset/blob/main/PHONEMEGUIDE.md) for any pronounciation examples.

the suggested recorded tempo is 120 BPM.
